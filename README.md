# Anonymised Freelancer Profile – GitHub Pages

Dieses Repository enthält eine zweisprachige, bewusst anonymisierte Freelancer-/Interim-Profilseite.

## Dateien

- `index.md` – deutsche Seite
- `en.md` – englische Seite
- `_config.yml` – GitHub-Pages/Jekyll-Konfiguration
- `_layouts/default.html` – HTML-Grundlayout
- `assets/style.css` – responsives Design

## Veröffentlichung auf GitHub Pages

1. Neues öffentliches GitHub-Repository anlegen.
2. Den **Inhalt dieses ZIP-Archivs** in die oberste Ebene des Repositories hochladen. Nicht den Ordner `freelancer-profile` als zusätzliche Ebene hochladen.
3. Änderungen auf den `main`-Branch committen.
4. In GitHub `Settings` → `Pages` öffnen.
5. Unter `Build and deployment` als Source `Deploy from a branch` wählen.
6. Branch `main` und Ordner `/ (root)` auswählen und speichern.
7. Nach dem Deployment zeigt GitHub unter `Settings` → `Pages` die öffentliche URL an.

## Pflege

Die fachlichen Inhalte liegen fast vollständig in nur zwei Dateien:

- Deutsch: `index.md`
- Englisch: `en.md`

Neue Skills, Projekte oder Erfahrungen können direkt in diesen Markdown-Dateien ergänzt werden. Das CSS muss dafür normalerweise nicht geändert werden.

## Anonymität

Wenn die öffentliche Seite nicht mit der eigenen Identität verknüpft werden soll, sollte auch das GitHub-Konto bzw. Repository keinen unmittelbar identifizierenden Namen tragen. Repository-Historie, Profilname, Commit-Autor und hinterlegte Links können ebenfalls Rückschlüsse auf die Identität ermöglichen.
